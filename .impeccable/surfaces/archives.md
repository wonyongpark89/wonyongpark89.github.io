# Teaching and Talks archives

## Purpose and mode

Read/Operate: open the appropriate archive list, choose a course or dated talk, and open the available HTML or PDF. Two precise directory/list additions inside the established Wonyong Park website; no visual identity replacement or concept tournament.

## Confirmed scope

Nine teaching entries and four talk/workshop entries. The user chose a shared-password gate for the archive lists only, and migration plus redirects for EDUC1033 and qual-analysis. Project websites and social-media carousels stay in place.

## Direction contract

- Inherit the existing ivory/deep-teal identity and Bricolage Grotesque/Figtree type system in `assets/css/site.css`.
- The first viewport shows the archive name, purpose and password form immediately.
- After unlock, meaningful course/date headings group plain divided rows. Each row names its material and exposes only the formats that exist.
- No raster assets or thumbnails are needed for this list task.
- Wrong-password feedback, Enter submission, per-category session state and a Lock archive button are required.
- Direct HTML/PDF files remain public, as explicitly chosen. Preserve content and application behaviour during the move.
- Narrow screens wrap navigation and put format links below each title. No horizontal scrolling.
- Existing reduced-motion and focus conventions are inherited. Unlock changes state directly, without an entrance animation.

## Verification

Desktop, mobile and the actual in-app viewport; closed, wrong-password, open and locked-again states; both archive categories; all catalogue file targets; representative migrated HTML, workbook assets and legacy redirects. Never submit sample data to the production workbook service.
